# Практика создания DSL в Kotlin

### 🗓 Дата проведения
**11 февраля 2025**

### 🎯 Цель
Практика создания удобных и читаемых DSL в Kotlin, изучение работы с инфиксными функциями и кастомными строителями объектов.

### 📌 Описание проекта
Этот репозиторий содержит код, демонстрирующий создание DSL (Domain-Specific Language) в Kotlin на примере работы с классом `User`. В рамках проекта реализованы:

- **Класс `User`** — содержит три свойства: `name`, `age` и `email`.
- **Методы деструктуризации и операторы `get` и `set`** для удобной работы с объектами.
- **Класс-строитель `UserBuilder`** для пошагового создания объектов `User`.
- **Использование инфиксной функции `to`** для задания значений полей в DSL-стиле.
- **Демонстрация работы в `main()`**:
    - Создание объектов `User` двумя способами (через `to` и прямое присваивание).
    - Пример деструктуризации и работы операторов `get` и `set`.
